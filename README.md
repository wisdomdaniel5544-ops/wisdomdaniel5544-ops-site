# AI Hustlers University Landing Page

A static, mobile-first landing page for TikTok traffic. It uses the supplied creator video, bright blue/lime contrast, and the Telegram CTA for AI Hustlers University.

## Free deployment

This repository is intended for GitHub Pages. The Pages workflow publishes the repository contents from `main` with no Manus watermark and no card required.

## CTA

The Telegram destination is `https://t.me/AIHUSTLERSUNIVERSITY` in `script.js` and the page markup.

## Content note

The page uses educational, non-guaranteed language. Review the landing page, business identity, and any required privacy/terms links before running paid traffic.
